# event-timeline-tiled

A read-only timeline of Bluesky runs stored in Tiled, shown as a Grafana
dashboard laid out like a video editor: the timeline of runs at the bottom, a
viewer for the selected run top right, run details and channels top left.

- [User guide](user/index.md): what the dashboard shows and how to read it.
- [Technical documentation](technical/index.md): architecture, the demo
  stack, development and testing.
- [Design](design/plan.md): the plan, decisions, the processing-run contract,
  the spike results and the design reviews.

Status: prototype, step 3 of the plan (vertical slice: timeline dashboard and adapter).
